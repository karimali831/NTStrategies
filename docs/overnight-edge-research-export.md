# Overnight Edge Portfolio: research session export

The session exporter is observational. The four Run 8 entry models, priority,
risk controls and order execution are unchanged.

## NinjaTrader setup

Run a dedicated Playback instance with the accepted ES contract and CME US
Index Futures ETH session. The chart and NinjaTrader timezone must be ET.

1. Enable **Research Telemetry**.
2. Enable **Research Session Export** (new; defaults to false).
3. Enable **Research Perturbation Scenarios** only when required. It evaluates
   78 hypothetical paths per actual trade and can slow long, accelerated runs.
4. First replay 23 and 26 October 2026 and verify data before the long run.

### Tick Replay is not required for this export

One-minute and five-minute bars are exported from OnBarUpdate. Playback using
historical **tick data** still delivers realtime market events to the strategy
and its existing OnMarketData research shadow. A standalone Strategy Analyzer
historical run does not normally invoke OnMarketData without Tick Replay, so
shadow and perturbation files may be absent there.

## Outputs

Folder: Documents\NinjaTrader 8\NinjexResearch\OvernightEdgePortfolio

| File prefix | Contents |
| --- | --- |
| overnight_edge_bars_ | Complete closed 1m OHLCV, 03:00–16:05 ET; reference levels and 5m cache timestamps |
| overnight_edge_context_ | Completed 5m OHLCV, ATR and EMAs; context bar time and rollover-observation time |
| overnight_edge_sessions_ | RTH/premarket bar coverage and day totals, including zero-trade days |
| overnight_edge_research_ | Existing candidate and trade rows, now with RunId, signal and 5m timing columns |
| overnight_edge_shadow_ | Existing qualified counterfactual outcomes, with expanded research row fields |
| overnight_edge_perturbation_ | Existing tick-path scenarios, now with RunId |

A normal full session has 390 completed RTH minute bars (09:31–16:00 ET).
Fewer bars are recorded honestly on an incomplete or shortened trading day.

RunId is common across all files generated by one strategy instance. For safe
joins, use RunId + Instrument + TradingDate, then the signal and entry times.
Old CSVs created before this update do not contain RunId and should never
be silently mixed with the newer playback.

## Automatically generate annotated PNGs

Install Python 3 and Matplotlib on the machine rendering the research images:

    python -m pip install matplotlib

From the repository root (PowerShell):

    python tools/render_overnight_edge_research.py --input "$env:USERPROFILE\Documents\NinjaTrader 8\NinjexResearch\OvernightEdgePortfolio" --output "C:\NinjexResearchCharts" --limit 5

Remove the limit after validating five dates. One PNG contains both a
09:30–16:05 full-session chart and a 09:30–11:45 PMH zoom. Qualified PMH
candidate markers and actual strategy trade entry/exit markers are overlaid
from this run's research telemetry. Zero-trade sessions also produce images.

One-date example:

    python tools/render_overnight_edge_research.py --input "C:\Research" --output "C:\Charts" --date 2026-10-26

All contract/run IDs are rendered by default, each with its own filename.
Use --run-id to select a particular research run.

## Smoke-test checklist

1. Run export enabled and disabled over exactly the same short playback.
   Confirm executed signals, time/price, trade count and P&L are identical.
2. Confirm one complete day has 390 RTH bars and that a no-trade RTH day
   still generates a session summary and PNG.
3. Cross-check entry and exit markers with the Playback101 executions grid.
4. On 26 October, compare Context5mBarEndET against SignalBarEndET and the
   5m rollover-observation time at the 09:50/09:57 PMH signals. The prior
   historical reconstruction used similar 5m values at later clock times.
5. Review file coverage and disk space before processing all five contracts.

### Research interpretation

Shadow signals overlap and ignore actual portfolio position/daily caps.
Hypothetical exits use last-price stop/target assumptions; they are not broker
fills and exclude execution costs. Do not sum shadow P&L as an achievable
portfolio. Validate selected hypotheses with the unchanged Run 8 control and
a separate filtered portfolio replay, with commissions and slippage.

EntryEndTime and FlattenTime are both 16:00 ET in the existing strategy.
Late-entry execution behaviour deserves a separate fix after the research
capture is verified; this PR deliberately does not change it.
